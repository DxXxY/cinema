# Together Cinema

Веб-проект для совместного просмотра видео через интернет: комнаты по ссылке, общий чат, синхронизация прямых видео и опциональная голосовая связь.

## Запуск

Требуется Node.js 18 или новее.

1. Распакуйте архив и откройте терминал в папке `together-cinema`.
2. Выполните `npm install`.
3. Выполните `npm start`.
4. Откройте http://localhost:3000.

Чтобы остановить сервер, нажмите `Ctrl+C`.

## Как пользоваться

1. Добавьте прямую ссылку на MP4/WebM/HLS (`.m3u8`) либо переключитесь на Embed.
2. Нажмите «Запустить».
3. Скопируйте ссылку комнаты и отправьте второму участнику.

Для синхронизации нужен доступный обоим участникам прямой URL видео. Обычные страницы видеосервисов часто не являются прямыми ссылками на файл. Embed-плееры могут запрещать встраивание и не гарантируют синхронизацию.

## Голосовая связь

Разрешите доступ к микрофону. В браузере микрофон обычно работает на `localhost` или на сайте с HTTPS. Используется WebRTC со STUN-сервером; для некоторых сетей понадобится TURN.

## Ограничения

- Комнаты хранятся в памяти и исчезают после перезапуска сервера.
- Это стартовый проект, не готовый публичный сервис. Перед публикацией добавьте rate limiting, проверку источников, логирование и меры безопасности.
- Зависимости HLS.js и шрифт загружаются с CDN.

### Источники видео

В режиме **VK / YouTube / Twitch** вставляйте обычную ссылку на ролик, канал, запись или клип: сайт автоматически попробует преобразовать её в URL встроенного плеера. Для Twitch при локальном запуске используется текущий hostname; на опубликованном сайте сервис должен быть открыт с корректным доменом и HTTPS. Для VK надёжнее всего брать ссылку через **Поделиться → Встроить**: часть роликов требует специальный hash или запрещает внешнее встраивание. Управление и синхронизация сторонних плееров ограничены их API.
