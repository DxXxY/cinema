# Together Cinema

Веб-проект для совместного просмотра видео через интернет: комнаты по ссылке, общий чат, синхронизация прямых видео и опциональная голосовая связь.

## Запуск

Требуется Node.js 18 или новее.

1. Откройте терминал в папке `together-cinema`.
2. Выполните `npm install`.
3. Выполните `npm start`.
4. Откройте http://localhost:3000.

Чтобы остановить сервер, нажмите `Ctrl+C`.

## Как пользоваться

1. На главной создайте комнату (имя, по желанию ссылка на фильм и «закрытая комната») или войдите по ID / ссылке-приглашению.
1. Вставьте ссылку на ролик VK Видео, YouTube, Twitch или прямую ссылку на файл MP4/WebM/HLS (`.m3u8`) — тип определяется автоматически.
2. Нажмите «Запустить».
3. Скопируйте ссылку комнаты и отправьте второму участнику.

Для синхронизации нужен доступный обоим участникам прямой URL видео. Обычные страницы видеосервисов часто не являются прямыми ссылками на файл. Embed-плееры могут запрещать встраивание и не гарантируют синхронизацию.

## Голосовая связь

Разрешите доступ к микрофону (работает на `localhost` или на сайте с HTTPS). Голос передаётся через сервер сайта по тому же соединению Socket.IO, что и чат: без WebRTC, TURN и сторонних сервисов, поэтому работает и там, где провайдер режет WebRTC. Звук сжимается до 16 кГц μ-law (~128 кбит/с) и отправляется только пока человек говорит. Лучше использовать наушники.

## Возможности комнаты

- Таймкоды участников, кнопка «Синхронизироваться» (подсвечивается, если ты отстал).
- Реакции поверх видео; кнопка ⛶ разворачивает плеер вместе с реакциями и субтитрами.
- Субтитры .srt/.vtt для прямых видео (UTF-8 или Windows-1251) — загружает один, видят все.
- История чата (последние 50 сообщений) сохраняется при перезагрузке страницы.
- Пустая комната живёт ещё 10 минут — фильм и чат не теряются при обрыве связи.
- «Закрыть комнату»: войти можно только по ссылке-приглашению с ключом.
- Голос: подсветка говорящего, выключение микрофона, громкость собеседников.
- На Render сервер сам пингует `/health` раз в 10 минут, чтобы не засыпать (`KEEP_AWAKE=0` отключает).

## Ограничения

- Комнаты хранятся в памяти и исчезают после перезапуска сервера.
- Это стартовый проект, не готовый публичный сервис. Перед публикацией добавьте rate limiting, проверку источников, логирование и меры безопасности.
- Зависимости HLS.js и шрифт загружаются с CDN.

## Структура

```text
together-cinema/
├── package.json
├── server.js             # Express + Socket.IO, сжатие, /health
├── src/
│   ├── rooms.js          # хранение комнат в памяти
│   └── socket.js         # обработчики событий комнаты, чата и голоса
└── public/
    ├── index.html        # главная: описание, создание комнаты, вход по ID
    ├── room.html         # комната (адрес /room/<id>)
    ├── home.css
    ├── styles.css
    └── js/
        ├── main.js       # точка входа комнаты, связывает модули
        ├── home.js       # главная страница
        ├── ids.js        # ID комнат и адреса /room/<id>
        ├── recent.js     # недавние комнаты (localStorage)
        ├── state.js      # общий socket и состояние комнаты
        ├── dom.js        # хелперы DOM, подсказки, ленивая загрузка скриптов
        ├── room.js       # вход в комнату, участники, имя, приглашения
        ├── player.js     # плеер: прямые файлы, HLS, синхронизация
        ├── vk.js         # управление VK-плеером
        ├── embed-url.js  # ссылки VK/YouTube/Twitch → embed
        ├── source-form.js# форма «Добавить фильм»
        ├── chat.js       # чат и его история
        ├── positions.js  # таймкоды участников
        ├── reactions.js  # реакции поверх видео
        ├── subtitles.js  # субтитры .srt/.vtt
        ├── background.js # анимированный фон
        ├── voice.js      # голосовая связь через сервер
        └── voice-worklet.js # захват/воспроизведение звука (AudioWorklet)
```

hls.js и VK API загружаются только когда открыт HLS-поток или VK-видео.


### Источники видео

Для **VK / YouTube / Twitch** вставляйте обычную ссылку на ролик, канал, запись или клип: сайт автоматически попробует преобразовать её в URL встроенного плеера. Для Twitch при локальном запуске используется текущий hostname; на опубликованном сайте сервис должен быть открыт с корректным доменом и HTTPS. Для VK надёжнее всего брать ссылку через **Поделиться → Встроить**: часть роликов требует специальный hash или запрещает внешнее встраивание. Управление и синхронизация сторонних плееров ограничены их API.
