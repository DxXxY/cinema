# Together Cinema для Windows

Приложение на Electron: открывает сайт https://cinema-geht.onrender.com в своём окне и добавляет то, чего нет в браузере. Всё, что меняется на сайте, сразу появляется и в приложении; пересобирать его нужно только при изменениях в этой папке.

## Что умеет

- **Трей:** закрытие окна сворачивает приложение в трей — голос и чат продолжают работать. Меню: новая комната, мини-плеер, автозапуск, горячие клавиши, обновления, выход.
- **Уведомления Windows** о сообщениях в чате и новых участниках, когда окно в фоне.
- **Мини-плеер поверх окон** (кнопка «▣ Мини-плеер» под видео или Ctrl+Alt+O).
- **Глобальные горячие клавиши:** Ctrl+Alt+P — пауза, Ctrl+Alt+M — микрофон, Ctrl+Alt+O — мини-плеер, клавиша Play/Pause на клавиатуре. Если сочетание занято другой программой, берётся запасное (Ctrl+Alt+K для микрофона, Ctrl+Alt+I для мини-плеера) — оно видно в меню трея.
- **Ссылки-приглашения** `togethercinema://room/<id>?key=…` открывают комнату в приложении (кнопка «Открыть в приложении» в комнате на сайте).
- **Автозапуск** с Windows — выключен, включается в меню трея.
- **Автообновление** из GitHub Releases.

## Разработка

Нужен Node.js 18+. Команды выполнять в этой папке:

```
npm install
npm start                      # запустить против живого сайта
$env:TC_SITE = "http://localhost:3000"; npm start   # против локального сервера
```

Если `npm start` запускается из терминала VS Code и окно не появляется — уберите переменную `ELECTRON_RUN_AS_NODE` (`Remove-Item Env:ELECTRON_RUN_AS_NODE`).

## Сборка и выпуск

```
npm run dist                   # установщик в dist/Together-Cinema-Setup.exe
```

Новая версия: поднять `version` в `package.json`, собрать и выложить в GitHub Releases файлы `Together-Cinema-Setup.exe`, `Together-Cinema-Setup.exe.blockmap` и `latest.yml` (или `npm run release` с переменной `GH_TOKEN`). Установленные приложения подтянут обновление сами.

Установщик не подписан сертификатом, поэтому при первом запуске Windows SmartScreen может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
